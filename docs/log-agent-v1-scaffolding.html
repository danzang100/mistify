2. Config format

config.yaml — single source of truth for pipeline behavior, loaded by common/config.py and validated against a pydantic model.

pipeline:
  chunk_window_minutes: 15
  chunk_overlap_minutes: 3
  max_agent_tool_calls: 20

adapters:
  auto_detect: true
  registered: [json_lines, elastic, loki, otlp]

bootstrap:
  sample_size: 100
  llm_fallback_sample_size: 40
  min_match_rate: 0.85

drain3:
  sim_th: 0.4
  depth: 4
  max_clusters: 2000
  persistence: file            # file | redis | kafka
  snapshot_path: .cache/drain3_state.json

redaction:
  mode: strict                 # strict | permissive | off
  entities: [email, ipv4, ipv6, credit_card, ssn, phone, api_key]

  path: .cache/incident_{incident_id}.sqlite

  adversarial_model: claude-sonnet-4-6   # can differ from main loop model

report:
  format: markdown             # markdown | html | pdf
  output_dir: ./reports

3. Adapter interface

adapters/base.py defines the contract every format adapter implements. Adapters are format-in, LogRecord-out — they never touch templating, redaction, or the scratchpad.

from abc import ABC, abstractmethod
from typing import Iterator
from log_agent.common.models import LogRecord

class LogAdapter(ABC):
    format_name: str

    @abstractmethod
    def detect(self, sample_lines: list[str]) -> float:
        """Return confidence score [0.0-1.0] that this adapter matches the sample."""

    @abstractmethod
    def parse(self, source: str) -> Iterator[LogRecord]:
        """Stream-parse the source into normalized LogRecord objects."""

common/models.py — the normalized record shape used everywhere downstream:

@dataclass
class LogRecord:
    ts: datetime
    source: str
    severity: str          # enum: TRACE|DEBUG|INFO|WARN|ERROR|FATAL
    raw: str
    fields: dict[str, Any]
    format: str             # originating adapter name, for traceability

adapters/registry.py — format detection dispatch:

def detect_format(sample_lines: list[str]) -> LogAdapter | None:
    scores = {a.format_name: a().detect(sample_lines) for a in REGISTERED_ADAPTERS}
    best = max(scores, key=scores.get)
    return ADAPTER_MAP[best]() if scores[best] >= 0.6 else None
    # None ⇒ falls through to bootstrap/ pipeline

      # dedupe + diversity-sample down to 20-50 lines

bootstrap/persist.py
  def save_adapter(template: InferredTemplate, name: str) -> None:
      # writes a new lightweight adapter (regex + field map) to
      # ~/.log_agent/adapters/{name}.yaml for reuse on future files

Validation gate: inferred template is run against the next 500–1000 lines; below min_match_rate (config, default 0.85) the bootstrapper attempts a second pass detecting 2–3 sub-templates (e.g. multiline stack traces mixed with kv-pairs) before giving up and falling back to raw-line mode.

7. Scratchpad database layer

scratchpad/schema.sql (also versioned as migrations/0001_init.sql):

CREATE TABLE log_events (
  id INTEGER PRIMARY KEY,
  ts TEXT NOT NULL, source TEXT, severity TEXT,
  template_id INTEGER REFERENCES templates(template_id),
  raw TEXT, fields_json TEXT
);
CREATE INDEX idx_log_events_ts ON log_events(ts);
CREATE INDEX idx_log_events_template ON log_events(template_id);

CREATE TABLE templates (
  template_id INTEGER PRIMARY KEY,
  pattern TEXT, occurrence_count INTEGER,
  first_seen TEXT, last_seen TEXT,
  severity_mix_json TEXT,
  anomaly_score REAL DEFAULT 0.0   -- frequency deviation from baseline
);

CREATE TABLE scratchpad_notes (
  id INTEGER PRIMARY KEY,
  step INTEGER, note TEXT,
  supporting_evidence_json TEXT NOT NULL,  -- mandatory; refs log_events/template_ids
  confidence TEXT
);

CREATE TABLE query_log (
  id INTEGER PRIMARY KEY,
  step INTEGER, sql_query TEXT, row_count INTEGER, ts TEXT
);
scratchpad/db.py

10. Entry points

CLI (cli.py)

log-agent ingest --source ./logs/incident.jsonl --format auto
log-agent investigate --incident-id 2026-08-30-checkout
log-agent report --incident-id 2026-08-30-checkout --format html

MCP server (mcp_server.py)

ToolArgsDescription
ingest_logspath/source, format?Runs adapter/bootstrap + templating + redaction, loads scratchpad
investigateincident_idRuns the bounded agent loop + adversarial check
get_reportincident_id, format?Returns the generated incident report

Redaction always runs regardless of entry point — MCP exposure does not bypass it.

12. Testing scaffolding

  • tests/fixtures/ — one representative sample file per adapter, plus sample_unknown_format.log to exercise the bootstrapper.
  • test_adapters.py — detect() confidence scoring + parse() correctness per format.
  • test_bootstrap.py — structural clustering accuracy, LLM-inference fallback (mocked), match-rate validation gate.
  • test_redaction.py — entity detection + hash-consistency (same value → same hash across lines).
  • test_scratchpad.py — schema migrations, read-only SQL enforcement, note evidence constraint.
  • test_agent_loop.py — tool-call budget enforcement, forced convergence path (mocked LLM responses).
